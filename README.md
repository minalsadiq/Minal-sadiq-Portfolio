## ✨ Key Features

- 📱 **Fully Responsive Design**  
  Optimized for desktop, tablet, and mobile devices.

- 🌙 **Dark / Light Mode**  
  Theme preference is saved for a better user experience.

- 🎨 **Modern UI**  
  Glassmorphism-inspired interface with gradient accents and clean visual hierarchy.

- 🧭 **Interactive Navigation**  
  Smooth navigation between portfolio sections.

- ✨ **Scroll Animations**  
  AOS-powered animations for a dynamic browsing experience.

- 💼 **Project Showcase**  
  Dedicated project cards with GitHub repositories and live demonstrations.

- 📩 **Contact Form**  
  Integrated contact form using FormSubmit.

- 💬 **WhatsApp Contact**  
  Quick communication through a floating WhatsApp button.

- ⚡ **Lightweight & Fast**  
  Built using standard frontend technologies without unnecessary frameworks or build dependencies.

## 🚀 Getting Started

This is a static frontend portfolio, so **no build tools or backend setup are required**.

### 1. Clone the Repository

```bash
git clone https://github.com/minalsadiq/Minal-sadiq-Portfolio.git
```

### 2. Navigate to the Project

```bash
cd Minal-sadiq-Portfolio
```

### 3. Run the Website

Open:

```text
index.html
```

directly in your browser.

You can also use **VS Code Live Server** for local development.
